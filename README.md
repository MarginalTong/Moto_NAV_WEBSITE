# MOTOR NAV · 工作台首屏

原生 HTML/CSS/JavaScript，使用本地 GSAP 3.15.0 核心与 ScrollTrigger。

## 预览

运行 `python3 -m http.server 8091`，访问 http://localhost:8091 。

初次进入显示用户提供的桌面照片。向下滚动约 9.8 屏：产品从桌面升起，逐渐转换成清晰正视图；背景变黑后，正视图在屏幕中央放大并保持一小段滚动距离，再轻微缩回。缩回开始时，导航光标离开表盘，沿弯曲路线驶向左上角，变为白色鸟形与橙色箭头 Logo。上滚可完全还原。没有额外宣传文案。

## 文件

- `index.html`：首屏照片、桌面修补层、产品裁切层。
- `assets/styles.css`：共用照片坐标空间、全屏适配和静态遮罩。
- `assets/app.js`：带 pin / scrub 的 GSAP Timeline，matchMedia 处理移动端和减少动态效果。
- `assets/vendor/`：从 npm 官方 gsap@3.15.0 包复制的四个压缩运行文件，保留原版权头。许可：https://gsap.com/standard-license 。
- `assets/images/workbench.webp`：用户原图的 WebP 压缩版，1448 × 1086。
- `assets/images/workbench-clean.webp`：内置 imagegen 生成的移除产品背景补图，仅局部遮罩使用。
- `.agents/skills/`：开发技能，不参与网页运行或发布。

## 性能与回退

只使用三张 WebP 和必要动画库，无视频、外部字体或第三方请求。原图高优先级显示，不以加载动画遮挡；图片解码完成后才增强动画。图片或脚本失败保留原图。尊重减少动态效果与节省流量偏好，改为静态首屏。主要动画使用 transform / opacity；路线通过 SVG 描边进度更新。产品复用原图请求；当前效果为照片分层动画，不是完整三维重建。桌面照片只在升起阶段轻微放大，特写使用独立的 1100px 正视图。

发布仅需 index.html 和 assets（images 中的生成说明可不发布）。服务器启用 Brotli/gzip 和正确的缓存更新策略。

## 验证

Chrome 检查原图首帧、产品升起、背景归零变黑、反向还原、390px 手机无横向溢出、减少动态效果时 pin 清理、禁用 JavaScript 静态回退以及浏览器错误；检查桌面中间帧、结束帧和手机结束帧截图。真实低端手机、Safari 仍需上线前验证。

## 正视图过渡

`product-front.webp` 是基于用户正视图、通过内置 imagegen 去除播放遮挡和背景的透明资产。完整提示词见 assets/images/GENERATION.md。两个产品层共用同一个运动父层，正视图完全显现后才隐藏旧图，以防过渡透出桌面。Timeline 的 center-closeup / settle 标签控制放大停留和缩回。

## 光标与 Logo

新增本地 MotionPathPlugin 和 MorphSVGPlugin（与核心同为 GSAP 3.15.0）。cursor-departure、logo-arrival、logo-complete 时间标签控制光标驶出、箭头变形与鸟翼展开。Logo 是根据用户图片手工重绘的 SVG：原黑色区域变白，箭头保持橙色。表盘光标离开时，用小范围 SVG 修补层延续屏幕路线。上滚时修补层、光标、Logo 与路径全部逆向恢复。

### 表盘路线对齐

光标在表盘内使用与 product-front.webp 相同的 1100 × 1100 坐标。原图路线经局部修补后，灰色底线和未行驶的白线共用同一条 34px SVG 路径；白线按已行驶长度退去，避免覆盖残边。光标中心和朝向直接采样该路径，结合产品当前缩放映射到页面坐标。表盘内外始终使用同一个光标，外部灰色轨迹从表盘路径终点以相同切线和宽度连续延伸至 Logo。灰线保留到结束，上滑时逐段恢复白线。

## 金属外壳与产品展示

Logo 完成后，外部灰线渐隐，表盘内灰线渐变恢复为白色路线，产品移到左侧，右侧出现「了解产品」。继续滚动时首屏保持 pin，产品绕垂直轴从正面转至背面；上滚可逆向还原。「了解产品」按钮打开手机 App 展示：手机先在右侧出现，再向左平移，右侧显示介绍文案；支持关闭按钮与 Esc 返回原滚动位置。手机改为产品居中、按钮在下方。

`assets/model.js` 构建轻量 CSS 3D 金属外壳：120 个连续高光侧面、SVG 后盖槽纹与金色触点、带厚度的十字安装卡扣。正面复用现有照片资产。模型根据参考图重建外观，非尺寸精确的 CAD 模型；无额外模型或纹理下载，无持续渲染循环。仍需真实 Safari / 低端手机验证三维面合成效果。

## 手机 App 介绍

`assets/showcase.js` 使用原生 dialog 和 GSAP 时间线展示手机界面与暂拟文案。手机与地图为参考截图的 HTML/SVG 示意重绘，不是真实地图服务。介绍涵盖路线规划、设备连接和转向提示，文案待产品功能确认后定稿。手机布局上下排列，减少动态偏好下立即展示。
